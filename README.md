## Запуск

Оба блокнота рассчитаны на **Google Colab**: необходимые зависимости устанавливаются в стартовой ячейке.

Для локального запуска создайте виртуальное окружение и установите зависимости из нужной лабораторной:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
