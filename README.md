# Лабораторная работа №1. Численные методы алгебры

Курс «Численные методы», ИТМО. Основной файл: [Numerical_Methods_Lab_1.ipynb](Numerical_Methods_Lab_1.ipynb).

## О работе

Реализация прямых и итерационных методов решения СЛАУ, метода Ньютона для нелинейных систем и исследование точности, обусловленности и сходимости. Практическая часть строится на двух физических моделях в MuJoCo:

- упругая решётка площадок (СЛАУ `Ku = f`);
- двухзвенный механизм (обратная кинематика методом Ньютона).

Готовые XML-модели, визуализация и регулятор предоставлены преподавателем. В собственных решателях запрещены `np.linalg.solve`, `inv`, `lu`, `cholesky` и аналогичные функции, они допустимы только для эталонных проверок.

## Запуск

Ноутбук рассчитан на Google Colab. Первая ячейка ставит `libosmesa6`, `mujoco` и `mediapy`, после чего нужно перезапустить сеанс.

Для локального запуска:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для MuJoCo нужен бэкенд OSMesa.
