# Лабораторная работа №2. Интерполяция, численное дифференцирование и интегрирование

Курс «Численные методы», ИТМО. Основной файл: [Numerical_Methods_Lab_2_Analysis_ipynb.ipynb](Numerical_Methods_Lab_2_Analysis_ipynb.ipynb).

## О работе

Реализация методов интерполяции, численного дифференцирования и интегрирования, а также исследование влияния выбора узлов и шага на точность приближения. Практическая часть строится на прикладных задачах и физической симуляции в MuJoCo:

- восстановление траектории брошенного мяча и манипулятора (полином Лагранжа, кубический сплайн);
- оценка скорости и ускорения автомобиля по зашумлённым измерениям лидара;
- рисование фигуры по экранным координатам роботом Unitree Go2 в MuJoCo (обратная двумерная интерполяция `(u, v) -> (pitch, yaw)`).

Код анимаций, MPC-регулятора и управления роботом предоставлен преподавателем. В разделах А–В численные методы реализуются самостоятельно, готовые функции библиотек допустимы только для проверок. В разделе Г используется готовая интерполяция из `scipy.interpolate`.
